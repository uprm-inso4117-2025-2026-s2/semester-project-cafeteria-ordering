== Description
Evaluate the usability and workflow efficiency of the staff dashboard across five core staff
operations: viewing active orders, updating order statuses, managing kitchen queues via the
dashboard, verifying pickups, and handling order issues via Special Status Requests.

== Execution Steps (Summary)
1. Log in as a staff user and navigate to the Orders screen.
2. Verify the Unread, Open, and Finished tabs and confirm order cards render correctly.
3. Use sort controls (Customer, Date, Order Number) and confirm list re-sorts.
4. Tap an order card and confirm a detail view opens with order information.
5. Trigger a status change from the detail view and confirm the order moves to the correct tab.
6. Navigate to the Dashboard and switch between Day, Week, Month, and Year tabs.
7. Review the Orders Overview table for all status row counts.
8. Observe the Customer Traffic card.
9. Attempt to locate a "Ready for Pickup" order and confirm a pickup action.
10. Navigate to Settings → Special Status Requests and attempt to review and act on requests.
11. Open and close the navigation drawer; verify all menu items and active state highlighting.
