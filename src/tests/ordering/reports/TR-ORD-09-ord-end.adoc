== Description

Since this test is focused on adding and removing from cart, we test the add to cart functionality by adding random items with random quantities and add-ons. We then test the remove from cart functionality by randomly removing items from the cart until it is empty. We check that the cart is updated correctly after each operation.

== Notes

Adding malformed ingredients to an item should not crash the system, but should log an error message indicating that the ingredient was not found. The same applies to modifying the base price or ingredients of an item with invalid data. Tested in FT-ORD-06-ord-modify-item-fuzz.
