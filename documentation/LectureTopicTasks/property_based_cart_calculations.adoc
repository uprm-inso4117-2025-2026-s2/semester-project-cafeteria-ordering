== Summary

This Lecture Topic Task #653 focuses on testing cart subtotal calculations using property based testing. Instead of checking only one hardcoded cart example, randomized prices, quantities, and add ons were generated to verify that subtotal calculations continue behaving correctly across different cart combinations.

== Properties Tested

. Cart subtotal never becomes negative.
. Adding items increases or maintains the subtotal.
. Reducing cart contents decreases or maintains the subtotal.
. Recalculating the same cart returns the same subtotal.
. Add on prices are included in subtotal calculations.

== Counterexample and Shrinking

When a property fails, fast check is able to display a counterexample showing the failing cart data. The library also attempts to shrink the failing case into a smaller and simpler example to make debugging easier.
